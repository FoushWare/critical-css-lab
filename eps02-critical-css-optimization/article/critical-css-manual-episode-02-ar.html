🎬 الحلقة ٢

Critical CSS يدوي — إزاي تعمله بإيدك

في الحلقة اللي فاتت فهمنا ليه الـ CSS بيوقف الرسم. دلوقتي الحل الأول والأبسط: تستخرج الـ Rules اللي بتغطي أول شاشة بس، تحطها Inline، وتأجّل الباقي. مفيش أدوات هنا — كله بإيدك، عشان تفهم المبدأ قبل ما نودّي الشغل للأدوات في الحلقة الجاية.

🧠 المبدأ

Above-the-Fold: إيه اللي المستخدم بيشوفه فورًا

"Above-the-fold" يعني أي جزء من الصفحة ظاهر في أول Viewport من غير Scroll. الفكرة إنك تجيب بس الـ CSS Rules اللي بتلوّن العناصر دي، وتسيب كل حاجة تانية (فوتر، أقسام تحت، Modal مخفي) تتحمّل بعدين.

⚠️
المشكلة الأولى اللي هتقابلها: "Above-the-fold" بيختلف حسب حجم الشاشة. Viewport موبايل مختلف عن Laptop مختلف عن شاشة 4K — يعني لازم تحدد Breakpoint معين تشتغل عليه (غالبًا الموبايل، لأنه الأكتر تقييدًا).
🛠️ الخطوات

إزاي تستخرج الـ Critical CSS بإيدك

1
افتح الصفحة في وضع Incognito وحدد الـ Viewportمثلًا 375×667 للموبايل — ده هيبقى المرجع بتاعك لأي حاجة "Above-the-fold".
2
افتح Chrome DevTools → Coverage TabCmd/Ctrl+Shift+P ثم اكتب "Coverage". هتشوف نسبة كل ملف CSS فعليًا مستخدمة في اللحظة دي.
3
سجّل الـ Coverage وانت بتحمّل الصفحةالأداة هتفرق بين الـ Bytes المستخدمة (أخضر) والمش مستخدمة (أحمر) في نفس الملف.
4
انسخ الـ Rules الخضرا بس في ملف critical.cssحافظ على نفس ترتيب الـ Rules زي ما هو في الملف الأصلي — الترتيب مهم عشان الـ Cascade (خصوصًا مع :hover و media queries).
5
حط الملف Inline، وأجّل الباقيزي ما هنشوف في الكود تحت — Inline للـ Critical، وPreload+Swap للباقي.
💻 التطبيق

الكود النهائي

<head> <!-- Critical: نسخته بإيدي من Coverage tab --> <style> .header{ ... } .hero{ ... } .hero h1{ ... } </style> <!-- الباقي: مؤجل، بيتطبق بعد أول Paint --> <link rel="preload" href="styles.css" as="style" onload="this.onload=null;this.rel='stylesheet'"> </head>
